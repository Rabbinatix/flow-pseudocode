# Changelog

## 1.1.0

- New command `rfpc` (also `npx @rabbinatix/flow-pseudocode`): `check`, `format` (`--write`, `--check`), `cheat-sheet` and
  `grammar`; output as text, JSON or GitHub annotations; exit codes 0, 1 and 2. No new dependencies.
- The library is unchanged, and so is the language: it is still FPC 1.0.

## 1.0.0

First public release of the reference implementation of Flow Pseudocode (FPC) 1.0 (spec first published 2026-09-30):
lexer, parser, validator, canonical printer, the constructs table, the EBNF grammar and the cheat sheet.
